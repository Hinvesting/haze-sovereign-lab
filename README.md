# 🦞 Haze-Sovereign Lab
**The Ultimate 100/100 Autonomous Agent Shell.**

Haze-Sovereign Lab is a high-performance, private infrastructure for deploying multi-agent swarms. It removes the complexity of environment setup, security, and data persistence, allowing you to focus entirely on agent logic.

## 🏗️ The Universal Shell
This is a "Plug-and-Play" architecture. Whether you are building for:
* **Business Intelligence**: Market research and data analysis swarms.
* **Operations**: Workflow automation and logistical coordination.
* **Content & Sales**: Viral marketing and lead generation pipelines.
* **Software Dev**: Automated coding, testing, and documentation crews.

## 🛡️ Core Infrastructure (100/100)
* **Sovereign Intelligence**: Local-only loopback binding. Your data, your rules.
* **Hybrid Compute**: Seamless integration with Ollama for local/cloud-hybrid inference.
* **Cloud Vault**: Deep Google Drive integration via Linux symlinks for 100% persistence.
* **Observability**: The `hwatch` engine provides a "Flight Recorder" for all agent activity.

## 🚀 Versatile Deployment
The shell is pre-configured to accept any **Skill** or **Tool** you define. Simply drop your logic into the `scripts/` folder and watch the swarm activate.

## 🌐 Secure Remote Access (Tailscale)
The Haze-Sovereign Lab is compatible with **Tailscale** for encrypted, private networking.
* **The Mesh**: Access your local 100/100 environment from your mobile device or remote laptop as if you were on the same Wi-Fi.
* **The Security**: Your connection is wrapped in a WireGuard® tunnel, ensuring your "Sovereign Intelligence" stays private even when you are on public networks.
* **Status**: Currently supported as an optional 'Encrypted Radio' for remote command and control.
